React Components 🧩

Components are independent and reusable bits of code. They serve the same purpose as JavaScript functions, but work in isolation and return HTML via JSX.

Demo: Reusable Components

In this demo, we use a single User component to display multiple users with different data.

👀 View Source
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>React Components</title>
    <script src="https://unpkg.com/react@18/umd/react.development.js" crossorigin></script>
    <script src="https://unpkg.com/react-dom@18/umd/react-dom.development.js" crossorigin></script>
    <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>
    <style>
        body { font-family: sans-serif; padding: 20px; }
        .user-card {
            border: 1px solid #ccc;
            padding: 15px;
            border-radius: 8px;
            margin-bottom: 10px;
            background-color: #fff;
        }
        .user-card h3 { margin-top: 0; }
        .status {
            display: inline-block;
            padding: 4px 8px;
            border-radius: 12px;
            font-size: 12px;
            color: white;
        }
        .online { background-color: #2ecc71; }
        .offline { background-color: #95a5a6; }
    </style>
</head>
<body>
    <div id="root"></div>

    <script type="text/babel">
        // Reusable User Component
        function User({ name, role, isOnline }) {
            return (
                <div className="user-card">
                    <h3>{name}</h3>
                    <p>Role: <strong>{role}</strong></p>
                    <span className={`status ${isOnline ? 'online' : 'offline'}`}>
                        {isOnline ? 'Online' : 'Offline'}
                    </span>
                </div>
            );
        }

        function App() {
            return (
                <div>
                    <h2>User List (Component Reuse)</h2>
                    <User name="Alice Johnson" role="Admin" isOnline={true} />
                    <User name="Bob Smith" role="Developer" isOnline={false} />
                    <User name="Charlie Brown" role="Designer" isOnline={true} />
                </div>
            );
        }

        const root = ReactDOM.createRoot(document.getElementById('root'));
        root.render(<App />);
    </script>
</body>
</html>

Function Components

The simplest way to define a component is to write a JavaScript function:

function Welcome(props: { name: string }) {
  return <h1>Hello, {props.name}</h1>;
}

Props

Props (short for properties) are the way we pass data from parent to child components. They are read-only.

function App() {
  return (
    <div>
      <Welcome name="Sara" />
      <Welcome name="Cahal" />
      <Welcome name="Edite" />
    </div>
  );
}

State

State allows components to create and manage their own data. Unlike props, state is private and fully controlled by the component.

import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>You clicked {count} times</p>
      <button onClick={() => setCount(count + 1)}>
        Click me
      </button>
    </div>
  );
}

Lifecycle

In function components, we use the useEffect hook to perform side effects (like fetching data or subscribing to events) which corresponds to lifecycle methods in class components.

import { useState, useEffect } from 'react';

function Timer() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    const timer = setInterval(() => {
      setCount((prev) => prev + 1);
    }, 1000);

    // Cleanup
    return () => clearInterval(timer);
  }, []);

  return <h1>Timer: {count}</h1>;
}
